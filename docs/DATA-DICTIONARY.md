# 数据定义

刷卡事件以event_id去重，card保留前导零。route支持1路/01等别名。event_time必须带偏移；业务日为Asia/Shanghai。result仅success可作为行程，失败刷卡隔离。reported为实扣人民币元。票价F1至2026-11-01前为2元，F2为2.50元。

跨线路换乘必须在上一次实际付费行程后60分钟内，恰好60分钟排除。同线路无优惠；零付费行程不能延长换乘锚点。先扣1元换乘优惠，再对卡号业务日施加6元封顶。每条基本票价=实算扣费+换乘优惠+封顶优惠。

## 夜间运营日（跨零点归属）

自然日00:00切分会把同一张卡的跨夜连续换乘拆成两天：后程在新的一天重新累计封顶，乘客被多扣；反过来若清晨首班车继续沿用上夜额度，早高峰又会少扣。因此业务日（输出列business_day）不按自然日，而按**全市统一运营日截止点**裁决：

- 参数night_cutoff为Asia/Shanghai本地时刻HH:MM，默认04:00，区间语义[start,end)。截止点之前（含零点后的凌晨段）归入前一运营日；截止点及之后归入当日。natural_day列保留自然日，仅用于展示跨夜归并，不参与计费。
- 逐线末班/首班时刻（app/service_day.py的LINE_SCHEDULE，可由parameters.line_schedule覆盖）只用于校验，不逐线归属：跨线路换乘链必须落在同一运营日，逐线裁决会把同一乘客的换乘链与封顶拆散，无法形成唯一结果。合法截止点必须严格落在每条线路(末班,首班)的收班—首班空档内（跨零点比较），否则以CUTOFF_OUTSIDE_GAP拒绝，整批不写入。
- 裁决结果对每位乘客在每个运营日唯一：换乘锚点与6元封顶均按(卡号,business_day)连续累计；截止点后的首班车开启新运营日，不继承前夜额度。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键保留第一条、完全相同行计重复；值冲突行隔离且保留原值。空文件、全空白、仅表头分开拒绝。

运行清单包括输入sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。
